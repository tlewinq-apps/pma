# Iterating on a frame

- **Variant (one frame):** the current frame has been renamed to `a-current.tsx`. Write the proposed take as
  `b-<idea>.tsx` beside it. Do not modify `a-current.tsx`.
- **Round (several frames):** copy the scene to `<scene>-v<N>/` first (the archive), then edit the live scene.
- Add a `<frame>.note.md` sticky note beside each changed frame with the customer quotes and your rationale.
- Place current and proposed side by side on `design/boards/pma-<issue>.json`.
